🧩 Bring Your Own Agents

  • Paste a JSON description of your own agent setup (see the on-page "Schema" help), or click Load example to start from a working one.
  • Press Render to see it drawn live — same engine as the map above, up to 20 agents.
  • If you defined flows, use Simulate the same way as the main map. Use Test a path the same way as "Test a Scenario."
  • Copy as Mermaid turns your graph into Mermaid syntax for GitHub, Obsidian, Notion, or anywhere else that renders it.
Try this: click Load example, press Render, then Test a path from "You" → "Reviewer." No direct rule connects them, but they're reachable through the Intake Agent — a real slip-through in the sample graph itself.

🔒 Privacy, in one line

Nothing on this page is ever sent anywhere or saved anywhere — no network calls, no cookies, no storage of any kind. Everything lives in memory for as long as the tab's open, and disappears on refresh.

AI Agent Flow

How one person runs real work through six specialized AI agents — with typed routing rules, escalation gates, and channels the system will not use even under a request that looks legitimate.

1 human · 6 AI agents · 17 governance edges · click through it below, it's live.

Why this is different from "we use AI"

Every action here traces to an explicit authority — nothing executes on an inferred or relayed approval. Work moves through defined gates before it reaches a decision-maker, delegation is explicit rather than assumed, and there are channels the system is built to never use, even under a live, direct-looking request. The result: fewer surprises, a real audit trail, and predictable delivery for anyone working with this business.

Not tied to one AI vendor

This governance model isn't locked to a single AI provider — it's the routing and accountability structure that matters, not which AI happens to be running underneath it. This exact visualization started life as a mirror of a different AI harness's own plugin before becoming this fully standalone build, proof the model itself travels. Any capable AI agent can be plugged into this same structure.

Schema — what to paste in

A JSON object with agents (id + label + optional role), edges (from/to/type/optional label), and optional flows (a label + an ordered list of edge ids, written as "from-to", to animate). Valid edge type values: auth, gate, delegate, relay, direct, review, route, handoff, redirect, blocked — these reuse the same colors/legend as the map above. Click "Load example" to see a working one.

Under the hood

      
Behind the scenes, this operation runs its own automation: scripts that flag stale risk items before they're forgotten, snapshot task load, auto-log handoffs between agents, and track AI cost per completed task — so the system checks its own health instead of relying on someone remembering to look.
